# Projeto de Análise de Dados Aplicativo Web

## Descrição do Projeto
Este projeto envolve o desenvolvimento de um aplicativo web destinado a fornecer um conjunto de dados relacionados a anúncios de vendas de carros. Os principais objetivos incluem:
- Criação e gestão de ambientes virtuais Python: configurar e gerenciar ambientes isolados para garantir que o aplicativo funcione de maneira eficiente e sem conflitos de dependências.
- Desenvolvimento do aplicativo web: projetar e construir o aplicativo utilizando frameworks e bibliotecas adequadas para garantir uma interface de usuário intuitiva e funcional.
- Implantação do aplicativo em um serviço de nuvem: disponibilizar o aplicativo para acesso público através de plataformas de nuvem, garantindo escalabilidade, segurança e acessibilidade.
O objetivo final é oferecer aos usuários acesso a dados detalhados sobre anúncios de vendas de carros de forma eficiente e interativa, proporcionando uma experiência de uso otimizada e acessível online.

## As tarefas são:
- Criar uma conta no GitHub
  - Acesse GitHub.com e crie uma conta.
  - Configure seu perfil e preferências iniciais.
- Criar um novo repositório no GitHub
  - No GitHub, vá até a aba "Repositórios" e clique em "Novo".
  - Escolha um nome para o repositório, adicione uma descrição e defina se será público ou privado.
  - Inicialize com um arquivo README.md e configure o .gitignore conforme necessário.
- Criar uma conta no Render
  - Acesse Render.com e registre-se.
  - Configure sua conta e adicione um método de pagamento, se necessário.
- Realizar uma análise exploratória de dados (EDA - Exploratory Data Analysis)
  - Carregar e limpar os dados utilizando Python (Pandas, NumPy).
  - Criar visualizações iniciais com Matplotlib e Seaborn para identificar padrões.
  - Analisar estatísticas descritivas e detectar valores ausentes ou discrepantes.
- Instalar o VSCode (Visual Studio Code)
  - Baixar e instalar o VSCode.
  - Configurar extensões úteis, como Python, Jupyter, GitHub Copilot e Prettier.
  - Configurar o ambiente de desenvolvimento com um interpretador Python adequado.
- Desenvolver o dashboard
  - Criar a estrutura inicial do dashboard utilizando bibliotecas como Streamlit, Dash ou Plotly.
  - Implementar visualizações e interações conforme a necessidade do projeto.
  - Testar e ajustar a responsividade e usabilidade da interface.
- Implementar a versão final do aplicativo no Render
  - Configurar o ambiente de produção no Render.
  - Conectar o repositório do GitHub ao Render para facilitar o deploy.
  - Realizar testes finais e ajustes para garantir a estabilidade da aplicação.

## Ferramentas e Bibliotecas utilizadas
- Python: Linguagem principal utilizada para a análise de dados, proporcionando flexibilidade e integração com diversas bibliotecas de ciência de dados e desenvolvimento web.
- Pandas: Biblioteca essencial para manipulação e análise de dados estruturados, permitindo a transformação e limpeza de grandes volumes de dados de maneira eficiente.
- Plotly Express: Biblioteca que facilita a criação de visualizações rápidas e interativas, proporcionando gráficos dinâmicos e de alta qualidade para explorar os dados de forma intuitiva.
- Streamlit: Biblioteca que permite a criação de aplicativos web interativos de forma simples e rápida, facilitando a construção de dashboards e interfaces de usuário para análise de dados.
- VSCode: Editor de código-fonte altamente funcional e personalizável, utilizado para o desenvolvimento e depuração do código, proporcionando uma experiência eficiente de programação.

- Criação de aplicativos web para diversos tipos e modelos de dados: Desenvolvimento de plataformas web interativas que permitem a manipulação e visualização de diferentes conjuntos de dados, adaptando-se às necessidades específicas de cada tipo de informação.
